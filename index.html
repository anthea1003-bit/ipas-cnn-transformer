兩條線各走一遍：每一站只講四件事——它在做什麼、進出形狀、參數量、對應的一行程式。深度只到考試會問的地方。所有例子都用同一組小數字，方便手算對照。

輸出形狀(32, 32, 3)參數0

站 1輸入影像

一張圖不是一個平面，是 3 層疊在一起的平面（R、G、B 各一層）。「通道」這個詞就是「幾層」。灰階 X 光只有 1 層，所以要接 ImageNet 模型時得 repeat 成 3 層。

# Keras 通道在最後 (H, W, C)；PyTorch 通道在前 (C, H, W)
input_shape=(32, 32, 3)          # Keras
x = torch.randn(N, 3, 32, 32)    # PyTorch，N 是批次大小
考點　Keras 是 channels-last、PyTorch 是 channels-first。題目給 (N, 3, 32, 32) 就是 PyTorch，第二個數字才是通道。
輸出形狀(32, 32, 64)參數1,792

站 2Conv2D：一排手電筒

一個 filter 是一支手電筒：照一個 3×3 的小窗，但要同時看穿全部 3 個通道，所以它身上有 3×3×3 = 27 顆旋鈕，再加 1 顆總亮度（bias）。這支手電筒從左上掃到右下，每照一格就輸出一個數，掃完得到一張 32×32 的「特徵圖」。64 支手電筒 → 64 張特徵圖疊起來，就是輸出的 64 個通道。

橘色小方塊：手電筒照這一格，27 個乘積加起來 + bias，寫進輸出特徵圖的對應位置。
符號意思從程式碼哪裡看本站
k核邊長(3, 3)3
C_in輸入通道上一站的最後一個數（第一層看 input_shape）3
C_outfilter 數 = 輸出通道Conv2D(64, …)64
—不影響參數量長寬 32×32、activation、padding、stride忽略

參數量 = k × k × C_in × C_out + C_out = 3×3×3×64 + 64 = 1,728 + 64 = 1,792

Conv2D(64, (3, 3), activation='relu', padding='same', input_shape=(32, 32, 3))   # Keras
nn.Conv2d(in_channels=3, out_channels=64, kernel_size=3, padding=1)             # PyTorch
考點　① 忘加 bias 得 1,728，必有此干擾選項。② 參數量與影像大小無關（權重共享），32×32 換成 224×224 參數還是 1,792。③ 反推題：給 896 與 k=3、C_out=32 → (896−32)÷(9×32) = 3 → 彩色。④ 兩層之間夾 Pooling，第二層的 C_in 是第一層的 C_out，Pooling 不改通道。
輸出形狀同輸入參數0

站 2b輸出多大：padding 與 stride

手電筒掃到邊緣時，最後幾格照不滿。same = 先在外圍補一圈 0，讓輸出長寬跟輸入一樣；valid = 不補，輸出會縮小。stride = 每次跳幾格，stride 2 就直接把長寬減半。

考點　「輸入 28×28，3×3 核、valid、stride 1，輸出多大？」→ 26×26。「同一層改 stride 2」→ 13×13。padding/stride 只改形狀，不改參數量。
輸出形狀(32, 32, 64)參數0

站 3ReLU：負的歸零

卷積算完的每個數，負的變 0、正的照過。沒有它，兩層卷積疊起來還是一個線性運算，疊再多層也等於一層——是非線性讓「深」有意義。

Conv2D(64, (3,3), activation='relu')     # Keras 寫在層裡
x = F.relu(self.conv1(x))                # PyTorch 另外呼叫
考點　隱藏層全用 Sigmoid + 很深 → 「前幾層權重不動、loss 降很慢」= 梯度消失，解法換 ReLU。Sigmoid 最大斜率 0.25，12 層連乘 0.25¹² ≈ 6×10⁻⁸。ReLU 正區斜率恆為 1，不會逐層衰減。
輸出形狀(16, 16, 64)參數0

站 4MaxPooling：每 2×2 只留最大

把特徵圖切成 2×2 的小格，每格只留最大值。長寬各減半、通道數不變、沒有任何參數。目的：縮小計算量，並且對小位移不敏感（瑕疵往右移一格，池化後看起來一樣）。

MaxPooling2D((2, 2))      # Keras
nn.MaxPool2d(2)           # PyTorch；kernel=stride=2
考點　Pooling 參數量 = 0。「哪些層有可學參數？」→ Conv、Dense（還有 BatchNorm）；Pooling、Flatten、Dropout、ReLU 都沒有。Max vs Average：Max 保留最強反應（找瑕疵），Average 保留整體平均（分類末端的 GlobalAveragePooling）。
輸出形狀(8, 8, 128)參數73,856

站 5第二組 Conv + Pool：通道變厚、長寬變小

同樣的手電筒，但這次每支要看穿 64 層，所以一支有 3×3×64 = 576 顆旋鈕 + 1 bias，共 128 支。CNN 越往後走的規律：長寬越小、通道越多，從「邊緣、顏色」升級到「形狀、零件」。

3×3×64×128 + 128 = 73,728 + 128 = 73,856，再接一次 Pool → (8, 8, 128)。

考點　不是 1,792 × 2。C_out 變 2 倍的同時 C_in 也從 3 變 64，所以是約 41 倍。「倍數直覺」只在 C_in 不變時才對。
輸出形狀(8192,)參數0

站 6Flatten：立方體拉成一條

8×8×128 的立方體，把每個數依序排成一條長 8,192 的向量。什麼都沒算，只是換個形狀好接 Dense。

Flatten()                 # Keras
x = x.flatten(1)          # PyTorch；從第 1 軸開始攤平，保留批次軸 0
考點　Flatten 後的長度 = 8×8×128 = 8,192，這個數決定下一層 Dense 的參數量。PyTorch 的 flatten(1) 那個 1 是「從哪一軸開始攤」，寫 flatten() 會把批次也攤掉。
輸出形狀(10,)參數81,930

站 7Dense + Softmax：投票

8,192 個數每一個都連到 10 個輸出，一條連線一顆旋鈕：8,192 × 10 = 81,920，再加 10 個 bias = 81,930。Softmax 把 10 個分數換成加總 = 1 的比例。

任務輸出神經元輸出激活Keras 損失PyTorch 損失

考點　PyTorch 分類輸出層裸奔：forward 回傳 logits，softmax 藏在 CrossEntropyLoss 裡；再加一次會雙重壓縮、訓練變慢。迴歸輸出層套 Sigmoid 會把預測壓在 (0,1)。「同時可能有刮痕＋斑點」= 多標籤用 Sigmoid，不是 Softmax。

整條線的程式碼

# Keras：形狀 (N, 32, 32, 3)
model = Sequential([
  Conv2D(64, (3,3), activation='relu',
         padding='same', input_shape=(32,32,3)),  # 1,792
  MaxPooling2D((2,2)),                            # 0
  Conv2D(128, (3,3), activation='relu',
         padding='same'),                         # 73,856
  MaxPooling2D((2,2)),                            # 0
  Flatten(),                                      # 0 → 8192
  Dense(10, activation='softmax')                 # 81,930
])
model.compile(optimizer='adam',
  loss='sparse_categorical_crossentropy',
  metrics=['accuracy'])
model.fit(X_tr, y_tr, epochs=10,
  validation_data=(X_val, y_val))
# PyTorch：形狀 (N, 3, 32, 32)
class Net(nn.Module):
  def __init__(self):
    super().__init__()
    self.conv1 = nn.Conv2d(3, 64, 3, padding=1)
    self.conv2 = nn.Conv2d(64, 128, 3, padding=1)
    self.pool  = nn.MaxPool2d(2)
    self.fc    = nn.Linear(8*8*128, 10)
  def forward(self, x):
    x = self.pool(F.relu(self.conv1(x)))  # (N,64,16,16)
    x = self.pool(F.relu(self.conv2(x)))  # (N,128,8,8)
    x = x.flatten(1)                      # (N,8192)
    return self.fc(x)                     # logits

criterion = nn.CrossEntropyLoss()  # 含 softmax
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

訓練一步在做什麼

每個 batch 走四拍：前向算出 logits → 損失算跟正確答案差多遠 → 反向傳播把「誰該負責」一層一層往回傳（鏈鎖律，每層梯度相乘）→ 優化器用梯度更新每顆旋鈕。梯度消失就發生在第三拍：連乘的每一項都小於 1，傳到前面就沒了。

for X, y in loader:
    optimizer.zero_grad()          # 清掉上一步的梯度（忘記會累加）
    loss = criterion(model(X), y)  # 前向 + 損失
    loss.backward()                # 反向傳播：算每顆旋鈕的梯度
    optimizer.step()               # 更新旋鈕

CNN 線上的三個經典模型，考試只問一句

模型一句話考什麼
VGG16全部 3×3 卷積一路疊，最後三層 Dense總參數約 1.38 億，其中約 1.24 億在全連接層；小核疊兩層 = 5×5 感受野但參數更少
ResNet每個區塊多一條 x 直達出口的捷徑，區塊只學殘差 F(x) = H(x) − x捷徑是相加不是跳過；F(x)→0 比學恆等容易，所以加深不會變差；梯度多一條斜率 1 的路
遷移學習拿 ImageNet 練好的權重當起點資料少＋領域近 → 全凍結只換頭；資料多＋領域遠 → 解凍後幾個區塊、小學習率；灰階 repeat 成 3 通道

形狀從頭到尾都是 (L, d_model) = (4, 8)。這是 Transformer 和 CNN 最大的手感差異：CNN 一路縮長寬、加通道；Transformer 每一站進出形狀不變，所以可以無限疊。

輸出形狀(4, 8)參數V × 8

站 1Tokenize → Embedding：字變向量

句子先切成 token 換成整數 id（查字典），再用 Embedding 表把每個 id 換成一條長度 d_model 的向量。Embedding 表就是一張 V × d_model 的查詢表，V 是字典大小，這張表本身是可學參數。

ids = tokenizer("退貨 要 幾 天")        # → [532, 17, 88, 203]，形狀 (4,)
emb = nn.Embedding(num_embeddings=V, embedding_dim=8)
x = emb(torch.tensor(ids))               # (4, 8)：每個 token 一列
考點　Embedding 不是 one-hot；one-hot 是 V 維稀疏，Embedding 是 d_model 維稠密且可學。「相似的字向量距離近」是它被學出來的性質。這一站和 RAG 的 embedding 向量檢索是同一個概念。
輸出形狀(4, 8)參數0 或 L×8

站 2位置編碼：把「第幾個」加回去

下一站的注意力是「每個字對所有字打分」，它看不出誰先誰後——把句子打亂，注意力算出來一樣。所以先給每個位置一條專屬向量，加到 embedding 上（形狀不變）。原論文用 sin/cos 固定公式（0 參數），BERT 用可學的位置表（L_max × d_model）。

x = emb(ids) + pos_enc[:4]               # (4,8) + (4,8)，逐元素相加，不是串接
考點　「為什麼 Transformer 需要位置編碼而 RNN 不需要？」→ RNN 逐字餵入，順序天然在裡面；注意力對所有字一視同仁，順序要另外給。是相加不是 concat。
輸出形狀(4, 8) ×3參數3 × 72

站 3做出 Q、K、V：同一個 x 乘三個矩陣

同一份輸入 x，分別乘 W_Q、W_K、W_V 三個 (8×8) 矩陣，得到三份 (4, 8)。用讀書會比喻：Q = 我提的問題、K = 每個人名牌上的專長、V = 每個人真正會講的內容。三個 W 各 8×8+8 = 72 顆旋鈕。self-attention 就是「Q、K、V 都從同一句話來」。

Q = x @ W_q;  K = x @ W_k;  V = x @ W_v    # 三個 (4,8)，來自同一個 x → self-attention
考點　W_Q、W_K、W_V 是可學參數，Q、K、V 是算出來的中間結果。「cross-attention」是 Q 來自一邊（decoder）、K 和 V 來自另一邊（encoder）。
輸出形狀(4, 8)參數0

站 4縮放點積注意力：比分數、換比例、混內容

① Q·Kᵀ：每個問題對每個名牌算相似度，得 4×4 分數表。② 除以 √d_k：分數壓小，免得 softmax 躺平。③ softmax 沿最後一軸：每一列換成加總 = 1 的比例。④ 乘 V：按比例把大家講的內容混起來。這一站沒有參數，旋鈕都在上一站的 W。

def attention(Q, K, V):                          # Q:(L,dk) K:(L,dk) V:(L,dv)
    scores = Q @ K.T / np.sqrt(Q.shape[-1])      # (L,L)；x ** 0.5 也是開根號
    w = np.exp(scores)
    w = w / w.sum(axis=-1, keepdims=True)        # 沿最後一軸，每列加總 1；keepdims 讓 (L,1) 能廣播
    return w @ V                                  # (L,dv)
考點　① 為什麼除 √d_k：點積是 d_k 項相加，d_k 越大原始分數越大 → softmax 進飽和區（S 曲線躺平）→ 梯度≈0。② 症狀對步驟：「比例加總≠1」→ softmax 軸錯（dim=0 應為 -1）；「學不動、比例極端」→ 沒除 √d_k。③ 輸出形狀 = (Q 的列數, V 的行數)，不是 K 的。④ 這裡的 softmax 在模型中間，每層每個 head 一個，不是最後分類的輸出層 softmax。
輸出形狀(4, 8)參數288 合計

站 5多頭：同一句話從幾個角度各打一次分

一個 head 只能學一種關係（例如「主詞對動詞」）。把 d_model = 8 切成 2 個 head，每個 head 用自己的 W 做 d_k = 4 的注意力，各得 (4, 4)，串接回 (4, 8)，再乘一個 W_O (8×8) 混合。參數量：W_Q、W_K、W_V、W_O 各 72，合計 288。

attn = nn.MultiheadAttention(embed_dim=8, num_heads=2, batch_first=True)
out, w = attn(x, x, x)     # self-attention：三個位置都放 x；out (1,4,8)，w (1,4,4) 是平均後的比例
考點　d_k = d_model ÷ h，所以 embed_dim 必須被 num_heads 整除（BERT-base 768÷12 = 64）。多頭是並行不是串行；串接（concat）不是相加。
輸出形狀(4, 8)參數16

站 6Add & Norm：捷徑相加，再拉回同一把尺

Add = 殘差連接，把站 3 之前的 x 直接加到注意力輸出上，跟 ResNet 是同一招：這一站就算學壞了，最差也是「原句原封不動遞過去」，所以能疊 12、24 層不變差。Norm = LayerNorm，把每個 token 那一列 8 個數標準化到均值 0、變異 1，再用兩個可學的縮放／平移（γ、β 各 8 個）調回來，共 16 個參數。

x = norm1(x + attn_out)     # 殘差 + LayerNorm，形狀 (4,8) 不變
考點　LayerNorm 是對一個樣本內的特徵做標準化（一列 8 個數），BatchNorm 是對一個 batch 內同一特徵做（一行 N 個數）。序列長度不一、batch 小 → LayerNorm；CNN 圖像 → BatchNorm。ResNet 的殘差和這裡的 Add 是同一個概念。
輸出形狀(4, 8)參數552

站 7FFN：每個 token 各自過兩層 Dense

注意力負責「字和字之間」，FFN 負責「每個字自己再想一下」。同一組權重，每個 token 獨立過：先放大到 4 倍（8→32，ReLU 或 GELU），再縮回 8。參數：8×32+32 + 32×8+8 = 552。再接一次 Add & Norm，一個 encoder 層就走完了。

ffn = nn.Sequential(nn.Linear(8, 32), nn.ReLU(), nn.Linear(32, 8))
x = norm2(x + ffn(x))       # 第二次殘差 + LayerNorm；出口仍是 (4,8)
考點　FFN 是 position-wise：對每個 token 獨立、權重共用，不看其他 token。一個 encoder 層的可學參數 = 注意力 288 + FFN 552 + 兩個 LayerNorm 32 = 872；真實模型的參數大部分在 FFN。
輸出形狀(K,)參數8×K + K

站 8輸出頭：從 (4, 8) 到答案

疊完 N 層還是 (4, 8)，最後要看任務：整句分類（意圖辨識）取 [CLS] 那一列或 4 列平均 → (8,) → Dense(K) + softmax；每個字一個標籤（NER）就每列各接 Dense；生成就 decoder 逐字預測下一個 token 的 softmax。

layer = nn.TransformerEncoderLayer(d_model=8, nhead=2, dim_feedforward=32, batch_first=True)
enc   = nn.TransformerEncoder(layer, num_layers=6)
h = enc(x)                   # (1, 4, 8)，6 層疊完形狀不變
logits = nn.Linear(8, K)(h[:, 0])   # 取第 0 個 token（[CLS]）做整句分類
考點　encoder（BERT）：雙向、看整句、做理解與分類。decoder（GPT）：單向、只看左邊、逐字生成，注意力要加 mask 遮住未來。「微調 BERT 做客服意圖分類」= 凍結或小學習率解凍 encoder，換掉輸出頭——跟 CNN 遷移學習同一個決策表。

兩條線共用的四個考點

這四個在兩邊都出現，考題常跨線出。

1. 梯度消失：同一個病，兩個發病點
CNN/MLP 版：隱藏層 Sigmoid，斜率 ≤ 0.25，反向傳播逐層連乘 → 前層梯度≈0，「前幾層權重不動」。解法：換 ReLU。
Transformer 版：不除 √d_k，原始分數太大 → 注意力 softmax 飽和（S 曲線躺平）→ 梯度≈0。解法：不能換掉 softmax（要有它才是比例），改成進 softmax 前除 √d_k。
共同解法：殘差連接給梯度一條斜率 1 的直達路——ResNet 的捷徑、Transformer 的 Add。
2. 參數量：三個公式推遍所有題
Conv2D：k×k×C_in×C_out + C_out（C_in 看上一層，Pooling 不改）。
Dense/Linear：in×out + out（in 是 Flatten 後長度，或 d_model）。
Embedding：V×d_model。
沒參數的：Pooling、Flatten、Dropout、激活函數、注意力的打分本身（旋鈕在 W_Q/W_K/W_V/W_O）。
變形題：反推 C_in（先減 bias 再除 k²×C_out）、哪一層最多（VGG16 是 Dense、Transformer 是 FFN）。
3. 形狀鏈：三條規則
矩陣乘法：(m×n)(n×p) = (m×p)，中間要相等。
Conv 輸出邊長：⌊(n+2p−k)/s⌋+1；same 且 s=1 → 不變；Pool 2×2 → 減半。
softmax/sum 的 axis：形狀括號從尾巴數，−1 是最後一軸，也就是最後一個中括號在跑；注意力沿 −1 讓每列加總 1；keepdims=True 讓 (L,1) 能和 (L,L) 廣播相除。
框架差異：Keras (N,H,W,C)、PyTorch (N,C,H,W)；序列都是 (N,L,d_model)（PyTorch 要 batch_first=True）。
4. 輸出層與損失、遷移學習：兩張決策表通用
輸出層：互斥多分類 Softmax+CE；可同時多標籤各自 Sigmoid+BCE；迴歸線性+MSE。PyTorch 的 CE/BCEWithLogits 已含激活，輸出層裸奔。
遷移學習：資料少＋領域近 → 全凍結換頭；資料多＋領域遠 → 解凍後幾層＋小學習率；大學習率會洗掉預訓練。ImageNet→ResNet50 和 BERT→意圖分類是同一張表。

走完自我檢核

先在心裡答完再展開。每題對應上面某一站，答不出就回那一站看圖。

Q1　Conv2D(96, (5,5)) 接在輸出 (14,14,48) 的層後面，參數量？
5×5×48×96 + 96 = 115,200 + 96 = 115,296。C_in = 48 是上一層的通道數。（站 2）
Q2　輸入 28×28，Conv2D(32,(3,3),padding='valid') → MaxPooling2D(2)，輸出形狀？
valid：28−3+1 = 26 → (26,26,32)；Pool 減半 → (13,13,32)。參數量與這兩個形狀無關，仍是 3×3×1×32+32 = 320（灰階 C_in=1）。（站 2b、4）
Q3　PyTorch 模型 forward 最後寫了 F.softmax(self.fc(x), dim=1)，損失用 nn.CrossEntropyLoss。問題？
雙重 softmax。CE 內含 softmax，再做一次會把比例再壓一次，梯度變小、訓練變慢。改回傳 self.fc(x)。（站 7）
Q4　Q (6×32)、K (10×32)、V (10×48)，注意力輸出形狀？softmax 沿哪個軸？
(6×32)(32×10) = (6,10) → softmax axis=−1 讓每列 10 個加總 1 → (6,10)(10×48) = (6, 48)。輸出 = (Q 的 token 數, V 的維度)。（Transformer 站 4）
Q5　把 d_k 從 64 改成 1024，其他不變，忘記除 √d_k 會怎樣？
點積是 1024 項相加，原始分數變大 → softmax 進飽和 → 比例接近 one-hot → 梯度≈0 → 學不動。這跟「隱藏層全 Sigmoid」是同一種梯度消失，但發病在注意力中間的 softmax，解法是除 √d_k 而非換激活。（共用考點 1）
Q6　nn.MultiheadAttention(embed_dim=100, num_heads=8) 會怎樣？
報錯。100 不能被 8 整除，每個 head 的 d_k = embed_dim ÷ num_heads 必須是整數。改 96 或 heads=4/5/10。（Transformer 站 5）
Q7　ResNet 的捷徑和 Transformer 的 Add & Norm 裡的 Add，哪裡一樣？
都是把區塊輸入 x 直接相加到區塊輸出，區塊只需學殘差 F(x)；F(x)→0 就是恆等映射，所以加深不會變差，梯度也多一條斜率 1 的路。（CNN 經典模型表、Transformer 站 6）
